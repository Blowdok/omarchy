# Identité de BV-LIHA

**BV-LIHA — Linux Intelligent Hybride Autonome** désigne le système personnel de **BlowVizion**. **LIHA** est le nom de son assistante intégrée. Conserver ces graphies dans les présentations et les interfaces.

BV-LIHA est un projet indépendant fondé sur Omarchy. Citer Omarchy, Arch Linux, Hyprland et Quickshell pour expliquer l’origine et la technologie du système ; ne pas présenter leurs auteurs comme les créateurs ou les soutiens officiels de la variante BlowVizion. La licence du code et les notices de provenance restent dans [LICENSE](LICENSE).

Le mot-symbole `logo.svg` et les monogrammes BV utilisent des tracés géométriques originaux, sans police incorporée. Le générateur `scripts/generer-identite-bv-liha.py` produit le SVG, les logos ASCII, les PNG principaux et l’aperçu du thème de démarrage ; il nécessite PySide6 pour les exports PNG, uniquement dans l’environnement de préparation. `--sans-png` permet de régénérer les fichiers texte et le SVG sans cette dépendance. Les fichiers exportés sont versionnés pour ne pas exiger Qt/Python lors de l’affichage d’un logo.

Les visuels BV-LIHA identifient la variante ; les images, marques et captures amont conservées comme documentation ou ressources de thèmes demeurent attribuées à leur origine. Leur présence dans le dépôt ne signifie pas qu’elles constituent l’identité propre de BlowVizion. Vérifier les ressources effectivement sélectionnées avant de produire une image d’installation ou une démonstration de la variante.
